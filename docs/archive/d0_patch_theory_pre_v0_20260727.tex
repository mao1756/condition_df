\large Theory note and implementation-level patch plan}

\date{\today}

\begin{abstract}
This note writes the theory behind the D0 patch plan.  D0 replaces terminal-reward bridge estimation from a source/noise distribution by reverse-time learning on free forward rollouts that start at data.  The key observation is that, for the symmetric finite-volume Dirichlet--Ferguson reference process, the time reversal of the free process started from the data law is itself a time-inhomogeneous Doob transform.  Its heat potential is the forward data density relative to the grid Dirichlet law, propagated by the same free semigroup.  The recommended estimator regresses the realized reverse physical edge transfer after subtracting the known reverse reference drift; its conditional mean is the physical Doob residual in the small-step limit.  This is the finite-volume analogue of DDPM denoising, but in conservative edge coordinates and with state-dependent harmonic mobility.  Raw forward-innovation regression remains a possible full-Euler-kernel parameterization, but its mean contains the reference-drift baseline and finite-step mobility corrections and must not be identified with the Doob shift alone.

The continuum Doob/Girsanov construction and the Lagrangian conditioning mechanism are in \cite[Sec.~3]{main-manuscript}.  The finite-volume grid, renormalized harmonic mobility, closed form, symmetric Hunt process, grid SDE, and terminal h-transform simulation rule are in \cite[Secs.~3--7]{eulerian-manuscript}.  The C0 weighted-innovation estimator and Brownian-coordinate loss are in \cite[Secs.~6--11]{c0-note}.  The C0--C3 failure record motivating D0 is summarized in \cite[Secs.~4--8]{experiment11-report}.
\end{abstract}

\section{Purpose of the D0 patch}

The original Level C program asked for a class-conditional Eulerian h-transform sampler on the MNIST mass simplex.  The previous estimators tried to learn a conditional law of the free reference process given that a terminal state looked digit-like.  In practice the free reference endpoints did not overlap the digit manifold: high-weight terminals were still noise blobs, C0 produced an almost zero learned/noise ratio, C1 suffered Girsanov effective-sample-size collapse, branch methods learned noise-level fluctuations, and the scalar value method learned a smooth value without producing a useful edge-gradient generator \cite[Secs.~4--8]{experiment11-report}.

D0 changes the measure on which the reverse field is learned.  Every training path starts at a lambda-floored data image and is then noised by the free conservative finite-volume dynamics.  For the theory baseline, the regression target is the realized reverse physical transfer with the known reverse reference drift removed, conditioned on the later state.  Thus the high-signal regime near data is actually sampled, rather than being reached only through an exponentially rare terminal event.

The central claim is:
\begin{quote}
\emph{D0 is not an abandonment of the h-transform program.  It is the h-transform whose terminal datum is the data density relative to the finite-volume reference law, propagated forward from data rather than estimated backward from a rare terminal reward.}
\end{quote}

\section{Finite-volume background}

This section fixes notation.  It is intentionally short; the detailed construction, closedness, Mosco program, boundary handling, and exact h-transform simulation rule are in \cite{eulerian-manuscript}.  The infinite-dimensional Doob transform behind the construction is in \cite{main-manuscript}.

\subsection{Grid state space and conservative incidence}

Let \(h=1/n\), let
\[
  \Ih = \{0,1,\ldots,n-1\}^d
\]
with periodic indexing, and let \(\SigmaH\) be the probability simplex
\[
  \SigmaH=\left\{s=(s_i)_{i\in\Ih}: s_i\ge 0,\quad \sum_{i\in\Ih}s_i=1\right\}.
\]
The reconstructed measure is
\[
  I_h(s)=\sum_{i\in\Ih}s_i\delta_{x_i^h}.
\]
A positively oriented edge is \(e=(i,\ell)\), with tail \(i\) and head \(j=i+e_\ell\).  For smooth \(F:\SigmaH\to\R\), define
\begin{equation}\label{eq:edge-derivative-d0}
  \partial_e^h F(s)=\frac{\partial_{s_j}F(s)-\partial_{s_i}F(s)}{h}.
\end{equation}
For an edge flux \(J=(J_{i,\ell})\), use the conservative incidence convention
\begin{equation}\label{eq:incidence-d0}
  (\dive J)_p=\sum_{\ell=1}^d J_{p-e_\ell,\ell}-\sum_{\ell=1}^d J_{p,\ell}.
\end{equation}
A positive edge flux moves mass from the tail to the head.  The state update is
\[
  \dot s=\dive J.
\]
This convention matches the finite-volume simulation rule in \cite[Sec.~7.4]{eulerian-manuscript}.

\subsection{Renormalized harmonic mobility}

The finite-volume program uses the renormalized harmonic mobility
\begin{equation}\label{eq:theta-d0}
  \theta_e(s)=\theta^h_{i,\ell}(s)=\frac{2\alpha_h+1}{\alpha_h}\frac{s_i s_j}{s_i+s_j},
  \qquad \alpha_h=\beta h^d,
\end{equation}
with value zero if \(s_i=s_j=0\).  The code sometimes uses a legacy fixed value \(\bar \alpha=1\) in place of \(\alpha_h\).  At a fixed grid this defines a legitimate practical reference, and the formulas below remain meaningful with that effective parameter.  It does not, however, keep \(\beta\) fixed as the grid is refined.  The Dirichlet--Ferguson scaling and finite-volume convergence claims refer specifically to \(\alpha_h=\beta h^d\); a fixed-\(\bar\alpha\) experiment must be labelled fixed-grid unless a separate refinement argument is supplied \cite[Secs.~4--6]{eulerian-manuscript}.

It is useful to write
\begin{equation}\label{eq:R-d0}
  R(a,b)=\begin{cases}
  \dfrac{a-b}{a+b},&a+b>0,\\[0.5em]
  0,&a=b=0.
  \end{cases}
\end{equation}
The canonical free Dirichlet drift edge flux is
\begin{equation}\label{eq:canonical-drift-flux-d0}
  b_e^0(s)=\frac{2\alpha_h+1}{h^2}R(s_i,s_j).
\end{equation}
The closed-form SDE and its boundary rules are derived in \cite[Sec.~6]{eulerian-manuscript}.

\subsection{The symmetric reference process}

The clean D0 theory uses a \(\nu_h\)-symmetric reference process.  Let \(\nu_h\) be the grid Dirichlet law
\[
  \nu_h=\operatorname{Dir}\bigl((\beta h^d)_{i\in\Ih}\bigr),
\]
and let \(L_h\) be the generator of the closed symmetric form \((\mathcal E_h,\mathcal D(\mathcal E_h))\).  In edge coordinates the canonical process can be written formally as
\begin{equation}\label{eq:canonical-edge-flux-d0}
  dK_e(t)=b_e^0(S_t)\,dt+\frac{\sqrt{2\theta_e(S_t)}}{h}\,dW_e(t),
  \qquad dS_t=\dive dK(t).
\end{equation}

For numerical calibration it is often convenient to use a time-change or noise schedule.  The exact symmetric version is
\begin{equation}\label{eq:symmetric-scaled-reference-d0}
  dK_e(t)=a(t)b_e^0(S_t)\,dt+\sqrt{a(t)}\frac{\sqrt{2\theta_e(S_t)}}{h}\,dW_e(t),
  \qquad a(t)>0.
\end{equation}
Equivalently, if the code parameter is \(w_\sigma(t)\), then exact symmetry corresponds to
\begin{equation}\label{eq:symmetry-scaling-condition-d0}
  a(t)=w_\sigma(t)^2,\qquad w_{\mathrm{free}}(t)=w_\sigma(t)^2.
\end{equation}
A code path that independently chooses \(w_{\mathrm{free}}\) and \(w_\sigma\) still has a well-defined Euler kernel and a valid conditional-innovation regression target, but the exact identification of the reverse dynamics with a \(\nu_h\)-symmetric h-transform is then no longer literal.  In that case the experiment should be reported as learning the reverse kernel of the chosen practical Euler reference.

\section{Standard terminal h-transform at fixed grid size}

For comparison with D0, recall the ordinary terminal h-transform.  Let \(g_h:\SigmaH\to(0,\infty)\) be bounded above and below away from zero.  Let \(T_h(t)=e^{tL_h}\) denote the free semigroup and set
\begin{equation}\label{eq:ordinary-h-potential-d0}
  u_t^h(s)=T_h(T-t)g_h(s).
\end{equation}
Then \(u_t^h\) solves the backward heat equation \(\partial_tu_t^h+L_hu_t^h=0\), \(u_T^h=g_h\).  The tilted path law from time \(\tau\) and state \(s\) is
\begin{equation}\label{eq:ordinary-tilted-law-d0}
  \frac{d\widetilde {\Pbb}^{h}_{\tau,s}}{d\Pbb^{h}_{\tau,s}}\Big|_{\mathcal F_T}
  =\frac{g_h(S_T)}{u^h_\tau(s)}.
\end{equation}
The h-transform keeps the same edge noise and adds the Brownian-coordinate shift
\begin{equation}\label{eq:brownian-shift-d0}
  \eta_e^u(t,s)=w_\sigma(t)\sqrt{2\theta_e(s)}\,\partial_e^h\log u_t^h(s).
\end{equation}
In physical edge-flux coordinates this is
\begin{equation}\label{eq:physical-conditioning-flux-d0}
  J_e^u(t,s)=\sigma_e(t,s)\eta_e^u(t,s)
  =\frac{2w_\sigma(t)^2}{h}\theta_e(s)\partial_e^h\log u_t^h(s),
\end{equation}
where \(\sigma_e(t,s)=w_\sigma(t)\sqrt{2\theta_e(s)}/h\).  This is the finite-volume conditioning flux from \cite[Sec.~7]{eulerian-manuscript}.  The C0 note uses the same Brownian-coordinate shift in its weighted innovation identity \cite[Secs.~6--8]{c0-note}.

The problem with C0--C3 was not the validity of \eqref{eq:brownian-shift-d0}.  It was the proposal measure: under free rollouts from the low-frequency source, the terminal digit event had negligible probability, so terminal weighting and branch weighting estimated a real but practically uninformative conditional mean \cite[Secs.~4--8]{experiment11-report}.

\section{D0 as a data-density h-transform}

\subsection{Data initialization and the density convention}

For each class label \(y\), let \(\mathcal A_y\) be the set of normalized MNIST training images with that label.  D0 uses the lambda-floored data convention
\begin{equation}\label{eq:data-floor-d0}
  S_0=(1-\lambda)a+\lambda\unif,
  \qquad a\in\mathcal A_y,
  \qquad (\unif)_i=|\Ih|^{-1},
\end{equation}
where \(0<\lambda<1\) is fixed once and used consistently in rollouts, previews, feature computations, and evaluation.

The floor has two roles.  First, it is an implementation convention defining the target distribution.  Second, it avoids the frozen-edge pathology \(\theta_e(s)=0\) on edges whose two endpoint masses are zero.  With \(\lambda>0\), every data-start state lies in the simplex interior.

There is a measure-theoretic qualification.  An empirical data distribution is still singular with respect to \(\nu_h\), even after adding a uniform floor, because it is a finite mixture of point masses.  The exact density h-transform statement below therefore requires one of the following regularizations:
\begin{enumerate}[label=\textup{(D\arabic*)},leftmargin=2.4em]
  \item replace the empirical data law by a small smooth density \(v_0^y\nu_h\) concentrated near the floored data images;
  \item or start the theoretical density identity at a small positive time \(t_{\min}>0\), where the free noising kernel has regularized the initial law.
\end{enumerate}
Directly sampling \eqref{eq:data-floor-d0} is a useful empirical approximation, but it is not by itself either regularization.  Results from time zero must therefore be reported as a discrete-data reverse-kernel experiment unless convergence from a specified smoothing or from \(t_{\min}>0\) is checked.

\subsection{Forward density and reverse transition}

Assume first that the class-conditional initial law is
\[
  p_0^y(ds)=v_0^y(s)\nu_h(ds),\qquad v_0^y\ge0,\quad \int v_0^y\,d\nu_h=1.
\]
Let \(p_t^y\) be the law at forward time \(t\) under the symmetric free reference process, and write
\begin{equation}\label{eq:forward-density-d0}
  p_t^y(ds)=v_t^y(s)\nu_h(ds),
  \qquad v_t^y=T_h(t)v_0^y
\end{equation}
for a time-homogeneous reference.  For a time-inhomogeneous symmetric time-change \(a(t)L_h\), replace \(T_h(t)\) by the corresponding forward propagator.

Define the reversed path
\[
  Y_\tau=S_{T-\tau},\qquad 0\le \tau\le T.
\]
Then \(Y_0\sim p_T^y\) and \(Y_T\sim p_0^y\).  By \(\nu_h\)-symmetry, the reverse transition from \(\tau\) to \(\tau+\delta\) is
\begin{equation}\label{eq:reverse-transition-d0}
  \widetilde T^y_{\tau,\tau+\delta}F(s)
  =\frac{1}{v_{T-\tau}^y(s)}
  T_h(\delta)\bigl(v_{T-\tau-\delta}^yF\bigr)(s)+o(\delta),
\end{equation}
with the obvious exact propagator version in the time-inhomogeneous case.  Thus the reverse process is a time-inhomogeneous Doob transform of the same free reference with heat potential
\begin{equation}\label{eq:data-heat-potential-d0}
  h_\tau^y(s)=v_{T-\tau}^y(s).
\end{equation}
Indeed \(h_\tau^y\) solves the backward equation in reverse time,
\[
  \partial_\tau h_\tau^y+L_hh_\tau^y=0.
\]
Consequently the reverse Brownian-coordinate h-transform shift is
\begin{equation}\label{eq:eta-rev-d0}
  \eta_{\mathrm{rev},e}^y(\tau,s)
  =w_\sigma(T-\tau)\sqrt{2\theta_e(s)}\,\partial_e^h\log v_{T-\tau}^y(s).
\end{equation}
The associated physical conditioning flux is
\begin{equation}\label{eq:reverse-physical-flux-d0}
  J_{\mathrm{rev},e}^y(\tau,s)
  =\frac{2w_\sigma(T-\tau)^2}{h}\theta_e(s)\partial_e^h\log v_{T-\tau}^y(s).
\end{equation}
This is the same object class as the usual terminal h-transform flux \eqref{eq:physical-conditioning-flux-d0}; the only change is the choice of terminal datum.  In C0--C3, the heat potential was generated from a terminal preference/reward and had to be estimated in a rare-event region.  In D0, the potential is the data density propagated by the forward noising process, so its high-signal region is directly populated by training trajectories.

\begin{proposition}[D0 reverse law as a Doob transform]\label{prop:d0-reverse-doob}
Under the symmetric reference assumption \eqref{eq:symmetric-scaled-reference-d0} and the density convention above, the time reversal of the free process started from the class-conditional data law is the h-transform with space-time potential \(h_\tau^y=v_{T-\tau}^y\).  Its Brownian edge shift is \eqref{eq:eta-rev-d0}, and its physical conservative edge flux is \eqref{eq:reverse-physical-flux-d0}.
\end{proposition}

\begin{proof}
For simplicity write the homogeneous case.  Let \(p_\delta(s,s')\nu_h(ds')\) be the transition kernel of the \(\nu_h\)-symmetric free process.  Bayes' formula gives
\[
  \Pbb(Y_{\tau+\delta}\in ds'\mid Y_\tau=s,Y\text{ label}=y)
  =\frac{p_\delta(s',s)v_{T-\tau-\delta}^y(s')\nu_h(ds')}{v_{T-\tau}^y(s)}.
\]
Symmetry gives \(p_\delta(s',s)=p_\delta(s,s')\), which yields \eqref{eq:reverse-transition-d0}.  Differentiating the h-transform transition family at \(\delta=0\) gives the generator \(L_h+2\Gamma_h(\log h_\tau^y,\cdot)\).  In edge Brownian coordinates this is exactly the Girsanov shift \eqref{eq:eta-rev-d0}; converting to physical edge flux using \(\sigma_e=w_\sigma\sqrt{2\theta_e}/h\) gives \eqref{eq:reverse-physical-flux-d0}.  The same argument applies to a symmetric time-inhomogeneous time-change after replacing \(T_h(\delta)\) by the short-time propagator.
\end{proof}

\section{Unweighted reverse physical-residual matching}

\subsection{Forward rollout cache}

For each cached trajectory:
\begin{enumerate}[label=\textup{(C\arabic*)},leftmargin=2.4em]
  \item sample a label \(y\) and a floored data start \(S_0=(1-\lambda)a+\lambda\unif\), \(a\in\mathcal A_y\);
  \item simulate the free reference process with learned control exactly zero;
  \item store the realized physical edge transfer \(\Delta K^{\mathrm{app}}_{k,e}\) actually passed to the conservative incidence update, together with the raw Gaussian innovation \(\xi_{k,e}\) for diagnostics and the qualified alternative below;
  \item store the per-edge limiter/mobility validity mask and aggregate floor-touched counts plus floor/renormalization correction magnitudes, but do not condition the physical-residual loss on whether a random intervention occurred.
\end{enumerate}

The strict baseline uses one elementary substep, \(r=1\).  Its realized reverse transfer is
\begin{equation}\label{eq:realized-reverse-transfer-d0}
  R_{k,e}=-\Delta K^{\mathrm{app}}_{k,e},
\end{equation}
because \(S_k=S_{k+1}+\dive R_k\) whenever no nonconservative repair is applied after the incidence update.  Write \(b_{k}^{\mathrm{ref}}(s)\) and \(\sigma_k^{\mathrm{ref}}(s)\) for the coefficients assigned by the implemented schedule to the forward interval \([t_k,t_{k+1}]\).  Their spatial arguments are evaluated at the later state.  Define the physical Doob-residual target
\begin{equation}\label{eq:physical-residual-target-d0}
  U_{k,e}=R_{k,e}
  -b_{k,e}^{\mathrm{ref}}(S_{k+1})\Delta t.
\end{equation}
For numerical conditioning choose one positive run-level scalar \(c_U\), fixed across states and edges, and define
\begin{equation}\label{eq:scaled-residual-target-d0}
  \widehat U_k=\Pi_{\mathrm{inc}}U_k,
  \qquad
  \widetilde U_{k,e}=\widehat U_{k,e}/c_U,
\end{equation}
where \(\Pi_{\mathrm{inc}}\) is the orthogonal projection onto the incidence-relevant edge subspace.  Unless explicitly overridden, the current implementation infers \(c_U\) once as the global root-mean-square of \(\widehat U\) on the initial cache, applies a declared positive floor, and then freezes that value across cache refreshes.  This deterministic rescaling preserves the projected conditional mean and keeps sampler units stable over a run.  State-dependent whitening by \(\sigma_e^{\mathrm{ref}}\sqrt{\Delta t}\) is a possible later variant, but it is not the implemented target and requires an explicit low-mobility convention.

The baseline D0 cache slice is keyed at the later state:
\begin{equation}\label{eq:d0-cache-slice}
  \left(S_{k+1},\; \tau_{k+1}=T-t_{k+1},\; y,\; R_k,\; U_k,\; \widehat U_k,\; \widetilde U_k\right),
\end{equation}
as a logical training slice, with a finite-value mask only if required for numerical safety.  The current NPZ stores \(R_k\), the interval index/schedule, later state, and \(c_U\); together with the adjacent run dynamics configuration, these derive \(U_k\), \(\widehat U_k\), and \(\widetilde U_k\) when summarizing or batching rather than duplicating those tensors.  Limiter and floor events are reported rather than selected away: conditioning on a random ``no intervention'' event would learn a selected transition law.  There is no terminal reward, no log weight, and no source variable as a model input.  The original data image \(a\), raw \(\xi_k\), intervention flags, and terminal state may be stored for diagnostics but are not model inputs.

This reuses C0's exact-substep bookkeeping but changes the supervised object.  C0 stored raw innovations, keyed them at the earlier state, and trained with self-normalized terminal weights \cite[Secs.~8--11]{c0-note}.  D0 keys realized reverse physical residuals at the later state and deletes the terminal weights.

\subsection{Population regression identity}

Let \(X=(\tau_{k+1},S_{k+1},y)\) be the model input for a D0 slice.  For any measurable predictor \(u=(u_e)_e\), define the population loss
\begin{equation}\label{eq:population-d0-loss}
  \mathcal L_{\mathrm{D0}}(u)=
  \E\left[\sum_e |u_e(X)-\widetilde U_{k,e}|^2\right],
\end{equation}
where the expectation is over the unweighted forward-from-data rollout law.  Then the minimizer is the conditional mean
\begin{equation}\label{eq:conditional-mean-target-d0}
  u_e^\star(\tau_{k+1},s,y)=\E\left[\widetilde U_{k,e}\mid S_{k+1}=s,\;Y=y\right].
\end{equation}
For the symmetric reference, in the small-step limit and away from limiter/floor interventions,
\begin{align}
  \E[\widehat U_k\mid S_{k+1}=s,Y=y]
  &=\Pi_{\mathrm{inc}}J_{\mathrm{rev}}^y(\tau_{k+1},s)\Delta t+o(\Delta t),
  \label{eq:physical-residual-identity-d0}\\
  u^\star(\tau_{k+1},s,y)
  &=c_U^{-1}\Pi_{\mathrm{inc}}J_{\mathrm{rev}}^y(\tau_{k+1},s)\Delta t+o(\Delta t).
  \label{eq:scaled-residual-identity-d0}
\end{align}
The sign is positive because \(R_k=-\Delta K_k^{\mathrm{app}}\) is already oriented in increasing reverse time.  Edge-cycle components lie in the null space of \(\dive\) and are not specified by the h-transform; the displayed identities therefore concern the projected, state-changing edge field actually used by the implementation.

\begin{proof}[Proof sketch]
Equation \eqref{eq:conditional-mean-target-d0} is the standard \(L^2\)-projection identity.  Proposition~\ref{prop:d0-reverse-doob} gives reverse physical drift \(b^{\mathrm{ref}}+J_{\mathrm{rev}}\).  Applying \(\Pi_{\mathrm{inc}}\) to the realized reverse transfer and subtracting the projected known reference term gives \eqref{eq:physical-residual-identity-d0}; division by the fixed scalar \(c_U\) gives \eqref{eq:scaled-residual-identity-d0}.  State-dependent mobility affects the finite-step remainder, which is why the equality is asymptotic rather than an exact identity for the implemented Euler kernel.
\end{proof}

\subsection{Qualified raw-innovation alternative}

Raw forward-innovation regression can still parameterize the full reverse Euler kernel, but it is not a regression of the Doob shift alone.  Suppose one uses the subtract-forward update
\begin{equation}\label{eq:subtract-forward-alternative-d0}
  s_{\mathrm{new}}=s-
  \dive\left[b^{\mathrm{ref}}(t,s)\Delta t
  +
  \sigma^{\mathrm{ref}}(t,s)\sqrt{\Delta t}\,(m_{\mathrm{full}}(t,s,y)+\zeta)\right].
\end{equation}
On a valid edge with coefficients frozen at \(s\), matching the reverse drift \(b^{\mathrm{ref}}+J_{\mathrm{rev}}\) requires
\begin{equation}\label{eq:full-innovation-mean-d0}
  m_{\mathrm{full},e}
  =-\sqrt{\Delta t}\left(
  \frac{2b_e^{\mathrm{ref}}}{\sigma_e^{\mathrm{ref}}}
  +\eta_{\mathrm{rev},e}\right)+o(\sqrt{\Delta t}).
\end{equation}
Thus \(\E[\xi_k\mid S_{k+1},y]\) contains a nonzero reference-reversal baseline even when \(v\equiv1\), as well as finite-step state-dependent-mobility corrections.  The earlier identification \(\E[\xi_k\mid S_{k+1},y]\approx-\sqrt{\Delta t}\eta_{\mathrm{rev}}\) is therefore not valid when \(b^{\mathrm{ref}}\ne0\).  This full-kernel alternative may be kept as an ablation, but it should use a distinct target-space name and must not be reported as direct Doob-residual matching.

\subsection{Training loss}

The recommended network head predicts the globally scaled physical residual mean:
\[
  u_\theta(\tau,s,y)\in\R^{d\times n\times n}.
\]
For a cached slice, project target and prediction onto the incidence-relevant edge subspace and use the per-slice loss
\begin{equation}\label{eq:masked-d0-loss}
  \ell_{\mathrm{D0}}(\theta)=
  \frac{1}{|E_h|}\sum_e\left|u_{\theta,e}(\tau_{k+1},S_{k+1},y)-\widetilde U_{k,e}\right|^2.
\end{equation}
The full training objective is
\begin{equation}\label{eq:d0-training-objective}
  L_{\mathrm{D0}}(\theta)=\E_{\mathrm{cache}}[\ell_{\mathrm{D0}}(\theta)]
  +\lambda_m\E_{\mathrm{cache}}\left[
  \frac{1}{|E_h|}\sum_e|u_{\theta,e}(\tau,S,y)|^2
  \right].
\end{equation}
For the exact conditional-mean baseline set \(\lambda_m=0\).  A positive output penalty changes the population minimizer by shrinking it, so it is an ablation rather than harmless regularization.  Parameter-space AdamW weight decay, gradient clipping, EMA weights, cache refresh, raw innovation diagnostics, and finite-value safety masks can be retained.  Intervention masks remain diagnostics.  There are no self-normalized sample weights.

\section{Reverse sampler}

\subsection{One-step sampler}

The controlled initialization for the first D0 experiments is the terminal bank
\begin{equation}\label{eq:prior-bank-d0}
  S_K\sim p_T^y,
\end{equation}
obtained by storing terminal states of the same calibrated forward discretization used to build the cache.  This removes initial-law mismatch from a test of the reverse field.  It is an empirical, generally class-conditional sample from \(p_T^y\), not an analytic DDPM prior and not automatically a sample from \(\nu_h\).  A DDPM-like prior claim requires a separate mixing test showing that \(p_T^y\) is label-independent and close to the proposed known prior.

Take stride \(r=1\).  Suppose the current reverse state is \(s=S_{k+1}\), at reverse time \(\tau_{k+1}=T-t_{k+1}\).  Draw independent fresh noises \(\zeta_e\sim N(0,1)\) and form the direct reverse transfer
\begin{equation}\label{eq:direct-reverse-transfer-d0}
  \Delta K_e^{\mathrm{rev}}=
  b_{k,e}^{\mathrm{ref}}(s)\Delta t
  +c_Uu_{\theta,e}(\tau_{k+1},s,y)
  +\sigma_{k,e}^{\mathrm{ref}}(s)\sqrt{\Delta t}\,\zeta_e.
\end{equation}
Advance in increasing reverse time with the same positive incidence convention:
\begin{equation}\label{eq:direct-reverse-state-update-d0}
  s_{\mathrm{new}}=s+\dive(\Delta K^{\mathrm{rev}}).
\end{equation}
This exposes the known positive reverse reference drift and learns only the Doob residual.  Evaluating coefficients at the later state is first-order consistent with the continuous reverse diffusion.  The fresh identity Brownian field implements the reference diffusion coefficient; it is not a claim that the finite-step conditional covariance of the stored forward innovation is pointwise the identity, or even pointwise smaller than the identity, for nonlinear state-dependent mobility.

A feasibility limiter may still be needed numerically, but applying the same named limiter in the two directions does not make the limited Euler kernel Bayes reversible.  The h-transform interpretation therefore requires limiter and floor/renormalization intervention rates to vanish under substep refinement.  If they remain material, the experiment learns a practical limited-kernel reverse process and must be labelled accordingly.

\subsection{Block stride}

The theory-lock baseline is exact-substep caching and \(r=1\).  For \(r>1\), a physical block target must subtract the known reverse reference drift at every actual intermediate state and schedule index:
\begin{equation}\label{eq:block-physical-residual-d0}
  U_k^{(r)}=-\sum_{q=0}^{r-1}\Delta K_{k+q}^{\mathrm{app}}
  -\sum_{q=0}^{r-1}b_{k+q}^{\mathrm{ref}}(S_{k+q+1})\Delta t.
\end{equation}
Conditioning this total only on \(S_{k+r}\), then distributing a predicted mean uniformly over \(r\) reverse substeps, is a coarse-kernel approximation; it is not implied by the one-step h-transform identity when the field, mobility, or schedule changes within the block.  Promote strides \(r=4\) and then \(r=8\) only after \(r=1\) passes, with reverse schedule indices applied in the order \(k+r-1,\ldots,k\) and with explicit no-degradation tests.

\subsection{State-dependent mobility and finite-step corrections}

The closed symmetric reference generator already fixes the complete free drift associated with the state-dependent harmonic mobility.  In the direct sampler, that known reverse reference drift is included explicitly and the learned term estimates the additional physical Doob flux.  At finite Euler step size, freezing coefficients at the later state and applying any limiter produce discretization-dependent corrections in \(U_k\).  Those corrections are not part of the continuum Doob field.  They must be controlled by exact-substep tests and \(\Delta t\)-refinement rather than justified by saying that a raw conditional innovation automatically absorbs them.

\section{Diagnostics and calibration}

D0 should start with diagnostics before training a model.  These diagnostics are part of the theory because the reverse h-transform interpretation assumes that the forward noising law actually connects data to a usable terminal prior without being dominated by numerical clipping.

\subsection{Phase 0: noising calibration}

Run free forward noising from floored data starts and log:
\begin{enumerate}[label=\textup{(P0.\arabic*)},leftmargin=2.9em]
  \item preview grids of \(S_k\) at \(k\in\{0,K/8,K/4,\ldots,K\}\);
  \item digit destruction curves: feature distance \(D_h(S_k,S_0)^2\), pixel correlation with \(S_0\), entropy, total variation, high-frequency/checkerboard energy;
  \item numerical health: clip fraction, mobility-threshold masked fraction, and frozen-edge fraction;
  \item a schedule sweep over \(w_\sigma\), \(K\), \(\lambda\), and, if kept, \(w_{\mathrm{free}}\).
\end{enumerate}
The gate is: by time \(T\), digit correlation should be near zero and entropy near its terminal plateau, while limiter and floor intervention rates are small and decrease under substep refinement.  A fixed-grid practical-kernel experiment may set a declared nonzero intervention tolerance; the strict h-transform baseline requires the intervention rate to be statistically indistinguishable from zero.  If no schedule destroys digits without intervention blowup, the limiter, substepping, or symmetry-compatible scaling should be fixed before training.

\subsection{Acceptance tests}

The first D0 training runs should be ordered as follows.
\begin{enumerate}[leftmargin=2.0em]
  \item \textbf{Zero-residual reference test.}  Start from \(\nu_h\) and run the direct reverse reference with \(u_\theta\equiv0\).  At a fixed grid it must preserve reference-law observables, and discrepancies must decrease under \(\Delta t\)-refinement.  Moment checks should include exact Dirichlet expectations and paired initial-to-terminal drift, not only comparison with one independent reference bank, whose sampling fluctuation can hide a common discretization bias.  This catches a wrong drift sign before training.
  \item \textbf{Overfit-one-image smoke test.}  Train on a single floored digit at \(r=1\) and initialize from that digit's forward terminal bank.  The reverse sampler must reconstruct the same digit before a full-data run is justified.  If the independent cache and optimization controls pass but the held-out residual objective does not improve, the failure is evidence that the chosen pathwise label is not learnable at that budget; it is not by itself proof of a sign or incidence bug.
  \item \textbf{Held-out forward reconstruction.}  Take a held-out forward path, start at its exact terminal state, and verify that reverse sampling reforms a same-class digit.  This tests the learned field without prior mismatch.
  \item \textbf{Per-time-bin signal.}  Plot target RMS, residual RMS, and learned/noise step ratio by time bin.  Unlike C0's nearly flat zero signal, D0 should show strong time dependence, with largest signal near the data end.
  \item \textbf{Sampler ablations.}  Compare deterministic reverse drift only, fresh-noise stochastic reverse, and control-strength sweeps.  The honest setting is strength one.  A source-initialized C0 comparison requires an explicit common cache adapter; the current D0 implementation has no rollout-initialization switch.
\end{enumerate}

\section{Positive-time implicit score after pathwise regression failure}
\label{sec:implicit-score}

The production block-residual studies provide a useful negative result.  The
elementary one-image task did not beat its zero predictor.  A larger independent
confirmation then tested five exact aggregation lengths with 128 paths and five
model seeds.  Its cache arithmetic and deterministic teacher passed, but no
stride beat the frozen training-only time-bin predictor on untouched audit
paths.  In particular, the apparent signal at the coarsest stride was explained
by time dependence rather than reproducible state dependence.  The confirmation
therefore closed with no confirmed conditional-mean signal and did not authorize
a sampler.

This does not imply that the positive-time marginal lacks a relative score.
It says that a noisy realized transfer is an ineffective supervised label for
that score under the tested conditioning and evidence budget.  A symmetric
Dirichlet form gives an alternative estimator that uses only marginal state
samples.

\subsection{Dirichlet-form score identity}

Fix a positive forward time \(t>0\), a label \(y\), and write
\(p_t^y=d\mu_t^y/d\nu_h\) whenever this density exists.  Put
\(f_t^y=\log p_t^y\).  For the symmetric reference generator \(L_h\), with
carr\'e du champ \(\Gamma_h\), integration by parts gives
\begin{equation}\label{eq:implicit-score-objective}
  \mathcal J_t(f)
  :=\E_{\mu_t^y}\!\left[\Gamma_h(f,f)+2L_hf\right]
  =\E_{\mu_t^y}\!\left[\Gamma_h(f-f_t^y,f-f_t^y)\right]+C_t,
\end{equation}
where \(C_t\) is independent of \(f\).  Thus a minimizer recovers the relative
score modulo the usual additive, time-dependent gauge.  Unlike the block target,
Eq.~\eqref{eq:implicit-score-objective} contains no realized reverse-transfer
label and no conditional first-moment regression.

Let \(N=n^2\), orient the two positive periodic edges from each grid cell, and
write
\[
  r_e(f)=\partial_{s_{\mathrm{head}(e)}}f-
          \partial_{s_{\mathrm{tail}(e)}}f,
  \qquad
  R_e(s)=\frac{s_{\mathrm{tail}(e)}-s_{\mathrm{head}(e)}}
               {s_{\mathrm{head}(e)}+s_{\mathrm{tail}(e)}}.
\]
In the fixed-grid implementation,
\begin{align}
  \Gamma_h(f,g)
    &=N\sum_e\theta_e(s)r_e(f)r_e(g),\label{eq:implicit-gamma}\\
  L_hf
    &=N\sum_e\left\{
       \theta_e(s)\,\partial_e^2f
       +(2\alpha+1)R_e(s)r_e(f)
      \right\}.\label{eq:implicit-generator}
\end{align}
The code minimizes the positively rescaled per-state objective
\(\{\Gamma_h(f,f)+2L_hf\}/(2N^2)\).  This normalization averages over the
\(2N\) oriented grid edges and changes neither the population minimizer nor the
physical flux.

\subsection{Detached-coefficient Hutchinson estimator}

The second-order term in Eq.~\eqref{eq:implicit-generator} is evaluated without
forming a dense \(N\)-by-\(N\) Hessian.  For a Rademacher edge vector \(z\), set
\[
  v=D_h^{\!*}\!\left(\sqrt{\theta(s)}\,z\right).
\]
Then \(v^\top\nabla_s^2f\,v\) is an unbiased trace estimator.  Mobility,
the ratio \(R_e\), and the tangent \(v\) are detached before the Hessian--vector
product.  Differentiating them inside the HVP would count state dependence of
the reference coefficients a second time, even though it is already encoded in
the canonical reference drift.  Training uses one probe per state; checkpoint
selection and audit use frozen independent multi-probe banks.

The learned scalar is
\begin{equation}\label{eq:implicit-model}
  f_{\phi}(s,\tau,y)=f_{\mathrm{lin}}(s,\tau)+
                     f_{\mathrm{UNet},\phi}(s,\tau,y).
\end{equation}
Here \(f_{\mathrm{lin}}\) is a frozen state-linear potential whose cell
coefficients vary through an eight-dimensional cubic B-spline basis in time.
It is fitted by a matrix-free float64 conjugate-gradient solve on training paths
only.  The U-Net is position sensitive, twice differentiable, and has an exactly
zero-initialized scalar output, so step zero equals the linear comparator.  A
neural pass must improve beyond this comparator, not merely rediscover the
schedule.

Once learned, the corresponding physical Doob edge flux is
\begin{equation}\label{eq:implicit-physical-flux}
  J^{\mathrm{Doob}}_e(s,\tau,y)
  =2Nw(\tau)\theta_e(s)r_e(f_{\phi}).
\end{equation}
Equation~\eqref{eq:implicit-physical-flux} is a score-to-flux identity.  The
present experiment does not insert it into a reverse integrator.

\subsection{Positive-time evidence design}

The density claim is deliberately restricted away from time zero.  On the
frozen \(K=512\), 256-substep temporal grid, every cached endpoint is at least
1,024 forward substeps from data, so \(t_{\min}=T/128\).  The authoritative
confirmation's 80 training paths and 24 checkpoint-selection paths may be
reused as state samples.  Its already inspected 24 audit paths are forbidden.
The implicit-score study generates 24 new audit paths and four distinct
preflight paths, each with 32 anchors allocated \(4,4,4,4,16\) over the five
reverse-time bins.

The implementation is fail closed at four cumulative gates.
\begin{enumerate}[leftmargin=2.0em]
  \item \textbf{Operator preflight.}  On a \(4\)-by-\(4\) grid, constants and
  total mass lie in the generator gauge, the product rule agrees with
  \(2\Gamma_h\), and a 4,096-probe quadratic trace estimate has relative error
  at most \(0.01\).  A production-device forward/backward smoke test must be
  finite and remain below the declared peak-memory budget.
  \item \textbf{State cache.}  Shards are deterministic and hash verified;
  train, selection, new audit, and preflight path identities are disjoint; all
  states are finite, strictly positive, and on the simplex; and the frozen
  intervention and correction thresholds continue to hold.
  \item \textbf{Synthetic controls.}  A time-varying nonuniform-Dirichlet
  teacher has an analytic nonlinear score and physical flux.  Teacher and null
  controls use 64 independent synthetic path clusters split (40/12/12) for
  training, checkpoint selection, and audit; they reuse only the frozen time
  plan, never physical state values or path identities.  The teacher must achieve
  at least \(0.90\) audit score gain, flux cosine at least \(0.98\) overall and
  \(0.95\) in every time bin, and relative flux error at most \(0.15\) overall
  and \(0.20\) in every bin.  A stationary-Dirichlet null must not have a
  positive whole-path audit lower bound relative to its frozen training-only
  state-linear comparator.
  \item \textbf{Physical score.}  Three seeds are selected using only the 24
  selection paths.  Two independent 32-probe audit banks must agree on positive
  improvements over both zero and the linear baseline, overall and at the data
  end.  One-sided 90\% bootstrap intervals resample the 24 whole audit paths,
  never states or model seeds.  Four-group median-of-means and two independent
  probe-free Stein-witness banks provide separate robustness checks.  Each bank
  contains 32 smooth periodic linear and 32 quadratic witnesses standardized
  using training states only.  The quadratic generator retains its exact edge
  Hessian term, and witness means are squared separately within each path and
  each of the five time bins before equal aggregation, preventing cancellation
  across time.  Cross-seed nonlinear-flux cosines must have median at least \(0.50\),
  with lower bound at least \(0.25\).
\end{enumerate}

A pass establishes only positive-time, fixed-grid, one-image relative-score
learnability beyond the declared linear comparator.  It does not establish a
finite-step Bayes reversal of the limiter, time-zero density, conditional
covariance, a known prior, multi-image quality, or spatial
Dirichlet--Ferguson convergence.  Only after this gate passes may a separately
named score-to-flux reconstruction experiment be designed.

\section{Density-ratio classification fallback for bounded controls}
\label{sec:density-ratio-controls}

The streamed implicit-control confirmation separates two conclusions.  Fresh
states and a smaller AdamW step size removed clipping and fixed-state
memorization, so the optimizer itself was healthy.  Nevertheless the bounded
teacher recovered only about one half of the weighted score signal and failed
the frozen flux thresholds, while one null selection panel nominated a
nonzero checkpoint whose signal disappeared on untouched audit states.  Thus
the Dirichlet-form identity remains valid, but the tested empirical
trace-plus-drift objective is not a trustworthy route to the required
derivatives.  No physical-score task or sampler is authorized by that result.

For the same bounded teacher, density-ratio classification removes the Hessian
trace estimate entirely.  At each matched positive-time anchor, draw one class
from the teacher marginal \(p_\tau\) and one from the Dirichlet reference
\(\nu_h\), with equal class prior.  For one raw scalar logit \(\ell\), the
balanced population logistic risk is
\begin{equation}\label{eq:density-ratio-logistic-risk}
  \mathcal R_\tau(\ell)
  =\frac12\E_{p_\tau}\!\left[\operatorname{softplus}(-\ell)\right]
   +\frac12\E_{\nu_h}\!\left[\operatorname{softplus}(\ell)\right].
\end{equation}
Pointwise minimization gives
\begin{equation}\label{eq:density-ratio-bayes-logit}
  \ell_\tau^*(s)=\log\frac{p_\tau(s)}{\nu_h(s)}.
\end{equation}
Exact balance at every time anchor is essential: unequal or time-dependent
class priors would add a log-odds term.  The implementation therefore matches
the complete time vector between classes in every batch and uses a single raw
logit, avoiding the gauge ambiguity of a two-logit classifier.

The derivative diagnostic acts on the raw logit, never on a sigmoid or a
clipped probability.  With the existing positive edge orientation,
\[
  r_e(\ell)=\partial_{s_{\mathrm{head}(e)}}\ell
             -\partial_{s_{\mathrm{tail}(e)}}\ell,
  \qquad
  J_e^{\mathrm{Doob}}=2Nw(\tau)\theta_e(s)r_e(\ell).
\]
For the bounded four-anchor teacher, the oracle logit is the analytic
\(\log(p_\tau/\nu_h)\) already used by the boundary controls.  For the
stationary null, both classes have law \(\nu_h\), so the unique normalized
Bayes logit is zero.  A null panel is formed by pooling independent Dirichlet
draws and applying a stateless balanced label swap within each matched time
anchor, preventing a class-specific random-number stream from becoming a
spurious feature.

Classification accuracy is advisory because this deliberately bounded
teacher is only weakly separable.  The gate instead uses held-out balanced BCE
improvement and the unchanged analytic score and flux thresholds.  One
discovery panel nominates exactly one checkpoint, a second independent panel
tests that nominee once, and two further untouched panels audit the frozen
choice separately.  Whole-path bootstrap intervals resample path clusters,
not individual anchors.  A rejected null nominee is still evaluated on both
audit panels so selection false discovery remains visible.

The first classification pilot detected a reproducible teacher signal at the
two smallest learning rates while every stationary null retained the analytic
zero comparator.  It nevertheless failed the optimizer-health gate: clipping
grew late in teacher training, reaching roughly \(0.30\) and \(0.21\), while
the frozen limit was \(0.10\).  Since no profile qualified, no untouched C/D
audit panel was generated.  This is an optimizer-variance result rather than
evidence for either a null false positive or accurate relative-score recovery.

For a fresh controls-only stability test, the same logistic risk can be
estimated with lower variance without changing its expectation.  Write the
bounded teacher as
\[
  p_\tau=(1-\epsilon)\nu_h+\epsilon\sum_j w_j(\tau)\nu_{h,j},
  \qquad \epsilon=\tfrac12,
\]
where \(\nu_{h,j}=\operatorname{Dirichlet}(\mathbf 1+e_j)\).  Draw independent
unit-rate Gamma coordinates \(G_i\), set
\(S_0=G/\sum_iG_i\), draw \(J\sim w(\tau)\) and an independent
\(E\sim\operatorname{Gamma}(1,1)\), and define
\[
  S_J=\frac{G+Ee_J}{\sum_iG_i+E}.
\]
Then \(S_0\sim\nu_h\) and, conditional on \(J\),
\(S_J\sim\nu_{h,J}\).  The paired per-anchor estimator is
\begin{equation}\label{eq:density-ratio-paired-risk}
  \widehat{\mathcal R}^{\rm pair}_\tau(\ell)
  =\frac{1-\epsilon}{2}\operatorname{softplus}[-\ell(S_0)]
   +\frac{\epsilon}{2}\operatorname{softplus}[-\ell(S_J)]
   +\frac12\operatorname{softplus}[\ell(S_0)].
\end{equation}
Its expectation equals \eqref{eq:density-ratio-logistic-risk}.  Relative to
sampling a Bernoulli mixture indicator, it integrates out that indicator and
uses the same reference state in the teacher's reference component and the
negative-class term.  Deterministic accumulation of several independent
paired microbatches averages this same estimator before one AdamW update; it
changes estimator variance and effective batch size, not the population
objective.  The loss multiplier, model, clipping norm, and physical score and
flux thresholds must remain frozen so that a pass cannot be manufactured by
changing optimizer units or the target law.

\subsection{Paired-pilot result and normalized-head coordinates}

The completed paired-mixture pilot passed every estimator preflight and all
twelve teacher/null tasks were finite.  Rao--Blackwellization was effective:
the measured loss-variance ratios relative to the original IID estimator were
approximately \(0.064\) and \(0.042\), and the corresponding directional-gradient
variance ratios were approximately \(0.099\) and \(0.073\).  Increasing the
deterministic accumulation level from \(2\) to \(8\) also improved the teacher
signal and reduced clipping.  At accumulation \(8\) and body learning rate
\(3\mathbin{\times}10^{-5}\), the selected teacher attained overall/data-end
score gains \(0.902/0.932\), flux cosines \(0.953/0.969\), relative flux errors
\(0.303/0.249\), and positive panel-B lower bounds.  Every null arm retained
the analytic zero checkpoint.  Nevertheless the teacher clipping fraction
was \(0.269\), above the frozen \(0.10\) limit, and no profile qualified.  Thus
no confirmation, physical training, or sampling was authorized.

Layerwise inspection localizes this failure to the scalar-output coordinate,
not to a lack of backbone capacity.  In the legacy boundary-smooth U-Net, let
\(H_i(s,\tau,y)\in\R^c\) be the final feature at cell \(i\), let \(M=n^2\), and
write the final \(1\mathbin{\times}1\) convolution as \((w,b)\).  The raw logit
is
\begin{equation}\label{eq:density-ratio-sum-head}
  \ell_{\rm sum}(s,\tau,y)
  =\sum_{i=1}^{M}\bigl(w^\top H_i(s,\tau,y)+b\bigr).
\end{equation}
On the \(28\times28\), \(c=32\) controls, the \(33\) final-head parameters
account for roughly \(99\)--\(99.9\) percent of the squared parameter-gradient
norm even though the backbone has about \(7.8\times10^5\) parameters.  The
same width-32 representation had already fitted the supervised analytic
teacher with score gain about \(0.999\), flux cosine about \(0.999\), and
relative flux error about \(0.036\).  The evidence therefore points to the
parameterization of the global scalar sum rather than an undersized model.

Introduce a versioned, function-equivalent mean head
\begin{equation}\label{eq:density-ratio-mean-head}
  \ell_{\rm mean}(s,\tau,y)
  =\frac1M\sum_{i=1}^{M}
       \bigl({w'}^\top H_i(s,\tau,y)+b'\bigr),
  \qquad w'=Mw,\quad b'=Mb.
\end{equation}
Equations~\eqref{eq:density-ratio-sum-head} and
\eqref{eq:density-ratio-mean-head} are identical as functions.  Consequently
their state gradients, edge scores, physical Doob fluxes, and boundary
behavior are identical.  For the same scalar loss,
\[
  \nabla_{w'}L=M^{-1}\nabla_wL,
  \qquad
  \nabla_{b'}L=M^{-1}\nabla_bL,
\]
while every backbone gradient is unchanged.

The AdamW update is coordinate-conjugate before clipping when the backbone
uses \((\eta,\varepsilon,\lambda)\) and the mean head uses
\begin{equation}\label{eq:density-ratio-head-adamw}
  \eta'=M\eta,
  \qquad \varepsilon'=\varepsilon/M,
  \qquad \lambda'=\lambda/M.
\end{equation}
Indeed the first moment scales by \(M^{-1}\), the second moment by \(M^{-2}\),
the adaptive step by \(M\), and the decoupled decay satisfies
\(\eta'\lambda'=\eta\lambda\).  EMA is conjugate under the same parameter
mapping.  The global Euclidean clipping operation is deliberately applied
after transforming to the mean-head coordinates and is therefore not
coordinate invariant; changing that optimizer geometry, without changing the
represented logit or population BCE, is precisely the proposed repair.

The normalized-head preflight first verifies functional and derivative
equivalence.  It separately verifies AdamW, EMA, boundary, and stream
equivalence.  Saved checkpoints from accumulation level \(8\) are replayed to
confirm finite layerwise gradients and a median legacy-head squared-gradient
share of at least \(0.95\).  Fresh training keeps width \(32\), the paired
estimator, EMA \(0.99\), accumulation \(8\), global clip norm \(1\), and the
frozen multiplier
\[
  c_{\rm BCE}=0.05173607018770852.
\]
A train/selection pilot tests body learning rates
\(3\mathbin{\times}10^{-5}\) and \(10^{-5}\); untouched three-seed
confirmation remains forbidden until one profile satisfies the unchanged
optimizer, teacher, and analytic-zero-null gates.

\subsection{Normalized-head result and oracle-qualified evidence power}
\label{sec:density-ratio-selection-power}

The normalized-head coordinate repair removed the optimizer pathology it was
designed to address: all four pilot tasks were finite, boundary admissible,
and had zero clipping.  Nevertheless no profile passed the sealed selection
gate.  This failure cannot yet justify an \(H^1\)-type trust region because the
same 16-path panel that rejected the learned teacher also rejected the exact
analytic Bayes logit.

For the saved 16-path forensic, let
\[
  \Delta_{a,p}
  =\log 2-\operatorname{BCE}
       \bigl(\ell^*(S_{a,p},\tau_{a,p}),Y_{a,p}\bigr),
  \qquad
  \ell^*=\log(p_\tau/\nu_h),
\]
and average anchors within each whole path before bootstrapping paths.  The
saved overall/data-end pairs were
\begin{align*}
  \text{panel A point estimate} &= 0.01621771096/0.01721000665,\\
  \text{panel A one-sided LB90} &= +0.00872031148/+0.00517841895,\\
  \text{panel B point estimate} &= -0.00174841445/+0.00326400978,\\
  \text{panel B one-sided LB90} &= -0.00913743689/-0.00565862046.
\end{align*}
Thus the observed sealed-panel-B rejection is an evidence-power failure: even
the population-risk minimizer could not satisfy the declared finite-panel
rule.

The next controls-only workflow therefore qualifies its evidence before
performing any optimizer step.  It first draws one independent 256-path
calibration panel with 32 anchors per path and the existing
\(4,4,4,4,16\) time strata.  The exact oracle must have finite, strictly
positive one-sided 99-percent whole-path bootstrap lower bounds both overall
and at the data end.  The panel is split by a predetermined rule into two
128-path halves, and each half must independently satisfy the existing
90-percent rule in both scopes.  Calibration paths are never reused for model
selection or audit.

The pilot then fixes fresh 128-path A/B panels for both teacher and null.  The
exact teacher must qualify the actual teacher A and B panels, overall and at
the data end, before training starts.  A failed panel is never resized,
regenerated, or replaced after inspection.  A passing pilot freezes one
profile and permits three-seed confirmation on entirely fresh, immutable
128-path A/B/C/D panels; every teacher panel is oracle-qualified before
training.  Whole paths, rather than anchors, remain the bootstrap unit.

No model or objective variable changes in this experiment.  Width remains
32; the spatial-mean head and coordinate-conjugate AdamW groups remain exact;
accumulation remains 8; and the body learning rates remain
\(3\mathbin{\times}10^{-5}\) and \(10^{-5}\).  Balanced BCE, EMA \(0.99\),
the global clip norm 1, and
\(c_{\rm BCE}=0.05173607018770852\) are frozen.  The pilot runs for 2,000
updates from root seed 260931.  A passing profile is confirmed for 4,000
updates with paired seeds 260941, 260942, and 260943.  The existing BCE,
score-gain, flux-cosine, relative-flux-error, analytic-zero-null, optimizer,
and three-seed thresholds are applied without weakening.

The conservative null rule remains the authorization gate.  A separate
non-authorizing multiplicity report distinguishes a discovery-panel event
from a reproduced null signal: if only panel A is positive while sealed panel
B rejects its nominee, the decision is
\nolinkurl{null_gate_multiplicity_inconclusive}, not optimizer instability.
The closed outcomes are

\section{Relation to the failed C0--C3 estimators}

D0 changes where the conditional mean is estimated.

\begin{itemize}[leftmargin=1.5em]
  \item \textbf{C0 weighted innovations.}  C0 asked for a Brownian shift under a rare terminal event using free rollouts from a source.  Since free terminals were not digit-like, the useful conditional signal on visited states was nearly zero.  D0 directly samples forward paths from data and regresses \(\E[U_k\mid S_{k+1}=s,y]\), the realized reverse physical transfer after subtracting the known reference drift.
  \item \textbf{C1 Girsanov proposals.}  C1 remained an importance-sampling correction for a rare terminal event, hence path weights collapsed in high dimension.  D0 has no terminal weights and no path-space ESS.
  \item \textbf{C2/C2.1 branches.}  Branch continuations from off-data free states mostly selected among noise blobs.  D0 puts the branch point distribution on actual noised data states.
  \item \textbf{C3 scalar value.}  Value MSE can be high-quality while spatial derivatives are poor.  D0 directly supervises the projected physical reverse residual rather than differentiating a fitted scalar value.
\end{itemize}

This explains why D0 is a natural fixed-grid Eulerian DDPM analogue: it moves the learning problem from a terminal rare-event estimator to a noising-process denoising estimator, while retaining the conservative finite-volume h-transform geometry.  The stronger Dirichlet--Ferguson and known-prior claims additionally require the manuscript \(\alpha_h=\beta h^d\) scaling, refinement evidence, and terminal mixing to a label-independent known law.

\section{Reconnecting D0 to terminal preferences}

D0 first learns the data-density h-transform.  After this generator reaches digit-like states, terminal preference conditioning can be layered on top.

\paragraph{Guidance.}
For a positive preference \(g_h(s)\), add a conservative guidance flux at sampling time:
\begin{equation}\label{eq:d0-guidance-flux}
  J_{\mathrm{guidance},e}(s)=\gamma\frac{2w_\sigma^2}{h}\theta_e(s)\partial_e^h\log g_h(s),
\end{equation}
or equivalently add the Brownian-coordinate shift
\begin{equation}\label{eq:d0-guidance-brownian}
  \eta_{\mathrm{guidance},e}(s)=\gamma w_\sigma\sqrt{2\theta_e(s)}\partial_e^h\log g_h(s).
\end{equation}
This is the conservative-flux analogue of classifier guidance.  It should be reported as an approximate h-transform of the learned data generator, not as the exact original terminal bridge unless corrected.

\paragraph{Reviving C1.}
Use the D0 generator as the proposal for Girsanov-corrected terminal tilting.  The proposal then has mass on digit-like paths, so ESS collapse should be substantially reduced.

\paragraph{Reviving C3.}
Estimate branch or value targets on-policy under the D0 generator's state distribution, with derivative regularization.  This addresses the C3 issue that value accuracy alone did not imply useful edge gradients.

\section{Risks and open implementation items}

\begin{enumerate}[leftmargin=2.0em]
  \item \textbf{Sign and time conventions.}  The direct baseline predicts \(u_\theta=\E[\widetilde U_k\mid\text{later state}]\).  Reverse sampling adds the direct transfer \(b^{\mathrm{ref}}\Delta t+c_Uu_\theta+\sigma\sqrt{\Delta t}\,\zeta\) through the positive incidence convention.  Use \(\tau=T-t\) and reverse schedule indices consistently.
  \item \textbf{Symmetry of the practical reference.}  The exact data-density h-transform theory requires the noising reference to be \(\nu_h\)-symmetric.  If the code decouples \(w_{\mathrm{free}}\) and \(w_\sigma\), D0 is still a valid reverse-kernel regression but is no longer exactly the symmetric h-transform above.
  \item \textbf{Initial-law singularity.}  Empirical data is singular relative to \(\nu_h\).  The rigorous density statement uses a specified smoothed data density or starts at a positive noising time.  Uniform flooring alone does not remove this singularity.
  \item \textbf{Conditional covariance.}  The finite-step conditional covariance given a later state is generally state-dependent and nonidentity; it need not be pointwise smaller than identity.  Fresh reference noise is the continuous-time reverse-diffusion prescription, not an exact conditional Euler-kernel covariance.  Log residual covariance on held-out forward steps.
  \item \textbf{Block bias.}  The strict baseline uses exact substeps and \(r=1\).  A block target conditioned only on \(S_{k+r}\), or uniform redistribution of its mean, defines an additional coarse-kernel approximation.
  \item \textbf{Limiter bias.}  A limiter or floor/renormalization changes the transition kernel.  Using the same implementation label forward and reverse does not establish Bayes reversal.  The physical target stores the applied transfer, but selecting the loss on a random no-intervention mask would introduce another conditional law.  Report interventions and verify that their rates vanish under refinement before making an h-transform claim.
  \item \textbf{Lambda defines the target.}  The generated samples live on the \(\lambda\)-floored simplex.  Use the same \(\lambda\) everywhere.
  \item \textbf{Grid scaling.}  Fixed \(\bar\alpha\) is a fixed-grid practical model.  A Dirichlet--Ferguson refinement claim requires fixed \(\beta\) and \(\alpha_h=\beta h^d\) across grids.
  \item \textbf{Prior claim.}  The terminal bank exactly controls initialization for the chosen forward discretization, but is empirical and class-conditional.  It becomes replaceable by \(\nu_h\) or another known prior only after quantitative mixing and label-leakage tests.
\end{enumerate}

\section{Minimal D0 checklist}

\begin{enumerate}[leftmargin=2.0em]
  \item Forward rollouts start at \(S_0=(1-\lambda)a+\lambda\unif\), with learned weight exactly zero.
  \item The symmetric reference relation \(w_{\mathrm{free}}=w_\sigma^2\) and the chosen \(\alpha_h\) convention are recorded; fixed-\(\bar\alpha\) runs are labelled fixed-grid.
  \item Realized applied physical transfers and raw Gaussian edge innovations are both stored.
  \item Limiter and low-mobility edge masks, aggregate floor-touched rates, and correction magnitudes are reported; the direct physical loss uses all finite projected transfers rather than conditioning on a random intervention mask.
  \item Exact-substep cache slices are keyed at \(S_{k+1}\), not \(S_k\); the baseline stride is \(r=1\).
  \item There are no terminal weights, no endpoint input, and no source \(z\) input in D0 mode.
  \item The network sees only time, state, and label: \((\tau,S_{k+1},y)\) or the consistently chosen equivalent time convention.
  \item Form \(U_k=-\Delta K_k^{\mathrm{app}}-b_k^{\mathrm{ref}}(S_{k+1})\Delta t\), where index \(k\) selects the same forward schedule interval, and train on \(\widetilde U_k=\Pi_{\mathrm{inc}}U_k/c_U\).
  \item The exact baseline uses per-slice MSE with output penalty \(\lambda_m=0\).
  \item Direct reverse sampling adds the known reference drift, learned residual, and fresh reference noise through the positive incidence convention.
  \item First runs initialize from the matching empirical forward terminal bank, without calling it an analytic prior.
  \item The zero-residual reference test and overfit-one-image test pass before any full dataset run.
  \item Per-time-bin target RMS, residual RMS, learned/noise ratio, clip fraction, frozen-edge fraction, entropy, TV, and preview grids are logged at every cache refresh.
\end{enumerate}

\paragraph{Cache generation.}
\begin{verbatim}
for path in range(cache_paths):
    y = sample_label()
    a = sample_training_image(label=y)
    s0 = (1 - lambda_floor) * normalize(a) + lambda_floor * uniform_grid()
    rollout = simulate_free_reference(
        state=s0,
        learned_weight=0.0,
        store_states=True,
        store_applied_edge_transfers=True,
        store_raw_gaussian_xi=True,
        store_limiter_validity_masks=True,
        collect_floor_and_renorm_counters=True,
    )
    prior_bank.add(rollout.states[K])
    for slice in range(time_slices_per_path):
        k = sample_start_index(0, K - 1)  # theory baseline: r = 1
        later = rollout.states[k+1]
        reverse_transfer = -rollout.applied_edge_transfers[k]
        cache.add(state=later,
                  time=reverse_or_forward_time(k+1),
                  label=y,
                  realized_reverse_transfer=reverse_transfer,
                  schedule_interval=k,
                  raw_innovation=rollout.raw_xi[k],
                  limiter_validity=rollout.limiter_validity_masks[k],
                  start_image_for_diagnostics=a)
initial_cache_residual_rms = rms_over_cache(
    project_incidence_relevant_edges(
        slice.realized_reverse_transfer
        - b_ref(schedule_interval=slice.schedule_interval,
                state=slice.state) * dt))
cache.physical_target_scale = max(initial_cache_residual_rms, scale_floor)
\end{verbatim}

\paragraph{Training step.}
\begin{verbatim}
batch = sample_cache(batch_size)
U_scaled = derive_projected_scaled_residual(
    batch, run_config, cache.physical_target_scale)
u_pred = project_incidence_relevant_edges(
    model(time=batch.time, state=batch.state, label=batch.label))
per_edge = (u_pred - U_scaled)**2
per_slice = per_edge.mean(edge_dims)
lambda_m = 0.0  # exact conditional-mean baseline
loss = per_slice.mean()
loss.backward()
clip_grad_norm_(model.parameters(), 1.0)
optimizer.step(); ema.update()
\end{verbatim}

\paragraph{Reverse sampling, stride one.}
\begin{verbatim}
s = sample_from_prior_bank(label=y)
for k in reversed(range(K)):
    tau = T - t[k+1]
    u = project_incidence_relevant_edges(ema_model(time=tau, state=s, label=y))
    dK_rev = b_ref(schedule_interval=k, state=s) * dt \
             + cache.physical_target_scale * u \
             + sigma_ref(schedule_interval=k, state=s) * sqrt(dt) * randn_like(u)
    s = s + incidence_divergence(dK_rev)
    s = limiter_floor_renorm_substep(s)
\end{verbatim}
